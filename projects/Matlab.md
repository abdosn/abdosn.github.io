# MATLAB projects

## OFDM Modulation
- **Overview:** An implementation for OFDM system with different modulation schemes and various channel conditions.
- **Technologies:** OFDM, BPSK, QPSK, 8PSK, 16QAM, 64QAM, AWGN channel, Rayleigh fading channel

## Morse Code Encoder & Decoder
- **Overview:** An implementation for Morse code encoder and decoder by converting text to sound Morse coded signal and vice versa.
- **Technologies:** Keying, security
